# 🔐 Захист від SQL-ін’єкцій у Python з використанням Streamlit

Цей проєкт демонструє, як захистити веб-додаток на Python від SQL-ін’єкцій за допомогою **параметризованих запитів** у `sqlite3`. Простий інтерфейс на Streamlit імітує **сторінку входу** та **реєстрацію користувачів**.

---

## 🚀 Можливості

- ✅ Реєстрація нового користувача (ім'я + пароль)
- ✅ Вхід в систему через логін-форму
- 🛡️ Захист від SQL-ін’єкцій (`' OR '1'='1` та ін.)
- ⚠️ Обробка помилок при підключенні до бази

---

## 🛠 Встановлення

1. Клонуйте репозиторій або скопіюйте код:

   ```bash
   git clone https://github.com/your-username/sql-injection-demo.git
   cd sql-injection-demo
2. Встановіть необхідні залежності:
   
   ```bash
   pip install streamlit
3. Запустіть додаток:

   ```bash
   streamlit run app.py

Демонстрація SQL-ін’єкції:
У формі входу спробуйте ввести:

Ім’я: ' OR '1'='1

Пароль: будь-який

✅ Результат: Вхід не відбудеться, бо параметри передаються окремо від SQL-запиту — це захищає від ін’єкцій.
